XPS 15 9570 — NixOS Migration Guide

Generated from a 17-file config built on the Debian machine. Read top-to-bottom.

Part 1 — Before the Wipe

Step 1: Git-init the NixOS config and push it somewhere retrievable
The installer needs to clone this repo. If you wipe before pushing, the config doesn't exist. 
cd ~/Programming/slop/desktop_config/nix
git init
git add .
git commit -m "NixOS 26.05 config for XPS 15 9570"
git remote add origin git@github.com:ShadyHippo/nixos-config.git  # or wherever
git push -u origin main
Step 2: Backup to NAS
Mount the SMB share first, then rsync everything irreplaceable. Omits Signal (intentional fresh start), Steam (reinstalls via library), and git repos (re-clonable). 
# Mount the anonymous SMB share
sudo apt install -y cifs-utils
sudo mkdir -p /mnt/nas
sudo mount -t cifs //192.168.0.20/deleteme /mnt/nas -o guest,uid=$(id -u),gid=$(id -g)

# rsync
rsync -avP --info=progress2 \
  ~/Programming/slop/desktop_config/nix/MIGRATION_GUIDE.html \
  ~/Programming/slop/desktop_config/nix/ \
  ~/Passwords.kdbx \
  ~/.ssh \
  ~/.config/{dolphin-emu,zellij,qBittorrent,fcitx5,gh,kdeconnect} \
  ~/.local/share/dolphin-emu \
  ~/.local/share/mupen64plus \
  ~/.var/app/org.libretro.RetroArch \
  ~/.zen \
  ~/Games \
  ~/Documents ~/Pictures ~/Videos ~/Music ~/Downloads \
  /mnt/nas/xps15-pre-nixos/

# Unmount when done
sudo umount /mnt/nas
What this captures: Passwords.kdbx, SSH keys+config+known_hosts (includes NAS/unraid shortcuts), all Dolphin GC/Wii/GBA memory cards+saves+texture packs, RetroArch saves+BIOSes, N64 saves, Zen browser profile (bookmarks/passwords/extensions), ROMs+texture pack master, personal media.
Step 3: Commit your uncommitted work

cd ~/.local/bin/my_scripts

# kickstart.nvim (untracked db_queries/)
cd ~/.config/nvim

Part 2 — On the NixOS 26.05 Installer USB

Boot the ISO, connect to Wi-Fi:

sudo nmcli device wifi connect SSID password PASS
Step 4: Partition (whole NVMe, UEFI) 
sudo parted /dev/nvme0n1 -- mklabel gpt
sudo parted /dev/nvme0n1 -- mkpart ESP fat32 1MiB 1GiB
sudo parted /dev/nvme0n1 -- set 1 esp on
sudo parted /dev/nvme0n1 -- mkpart primary 1GiB 100%
sudo mkfs.fat -F32 /dev/nvme0n1p1
sudo mkfs.ext4 -L nixos /dev/nvme0n1p2
sudo mount /dev/disk/by-label/nixos /mnt
sudo mkdir -p /mnt/boot && sudo mount /dev/nvme0n1p1 /mnt/boot
Step 5: Clone config + generate hardware file 
sudo nix-env -iA nixos.git
git clone https://github.com/ShadyHippo/nixos-config.git /mnt/config
cd /mnt/config
sudo nixos-generate-config --root /mnt --dir .

# nixos-generate-config overwrites configuration.nix — restore ours:
git checkout configuration.nix
# Keep the generated hardware-configuration.nix (has your real UUIDs)
Step 6: Install 
sudo nixos-install --flake /mnt/config#xps15
# When done, reboot into the new system.

Part 4 — Verify Everything Works

WiFi: Should connect automatically on boot (Intel AC 9560, iwlwifi driver). If not: sudo nmtui to connect manually.
NVIDIA dead: 
cat /sys/bus/pci/devices/0000:01:00.0/power/runtime_status
Expected: suspended
Undervolt applied: 
sudo undervolt read
Expected: core ≈ -130 mV, GPU ≈ -150 mV, short 45W/0.002s, long 35W/28s
Pinyin works: Open ghostty, Ctrl+Super+A, type "nihao". Should output 你好.
Resolution presets: Press $mod+F10, $mod+F11, $mod+F12. Screen res should change (720p / 1080p / 4K). F12 restores desktop mode.
Printer: System Settings → Printers → Brother MFC-J6550DW should appear via driverless IPP.
Screenshot snip tool: $mod+Shift+s — should show slurp's rectangle selector with live pixel measurements in the corner.
Zen profile: Open Zen — bookmarks, extensions, and saved passwords should be intact from the rsync'd ~/.zen.

Key Config Decisions (for future-you)

  • NixOS version: 26.05 stable. No unstable channel pulled — except VS Code (unstable input swap) and neovim (nightly overlay)
  • Disk: ext4 plain, no LUKS, no swap (suspend only)
  • WiFi: Intel AC 9560 (replaced the stock QCA6174). iwlwifi driver, mature + in-kernel. Firmware via hardware.enableRedistributableFirmware
  • dGPU: GTX 1050 Ti permanently parked in D3 — blacklist all nvidia/nouveau modules, udev power/control=auto
  • Undervolt: services.undervolt — core -130, GPU -150, PL1 35W/28s, PL2 45W/0.002s. BIOS 1.31.0 allows it (past the 1.16 threshold). Check sudo undervolt read after any BIOS update via fwupd
  • Microcode: hardware.cpu.intel.updateMicrocode = true — applies Intel CPU microcode at boot. Primarily for hardware errata stability, not just security mitigations
  • Zen browser: community flake (0xc000022070), not in nixpkgs. uBlock pre-installed via enterprise policy. Profile backs up/restores from ~/.zen
  • Maki + OpenCode: mise-managed (mise up updates both). Static musl binaries — no nix-ld needed
  • yt-dlp: system package. deno (via mise) is its JS runtime — yt-dlp's own recommended default. Required for YouTube extractors
  • Rust: rustup lives outside nix by choice. cargo-leptos/templ/air installed via cargo
  • Touchpad: natural scrolling ON, disable-while-typing OFF (jank history)
  • No auto-lock: lock only before suspend (swayidle). You run remote agents over SSH
  • Signal: Fresh start, history intentionally not migrated. Purge manually via Settings → Storage when disk fills
